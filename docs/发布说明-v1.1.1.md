# 拾光集 C 版 1.1.1 · 发布说明

这一版主要是**播放器换了界面**：从「一个画面 + 右边一条列表」改成和图片模块一样的
**视频库网格**（左边文件夹、右边缩略图墙）。另外修掉音乐模块一个很烦的老毛病
——点歌不按你看到的顺序播。

## 下载

- `ShiGuangJi-1.1.1-win64.zip`
- 解压后双击 `ShiGuangJi.exe` 即可，不用安装
- 需要 **Microsoft Edge WebView2 Runtime**（Win11 / 新版 Win10 一般自带）
- 数据仍在 `%APPDATA%\shiguangji\`，和 1.0.0 / 1.1.0 / 原 Electron 版同一个位置，
  **直接覆盖旧目录即可，存档不用动**

> 升级注意：主程序与 `modules\*.dll` 要**整包一起换**。只换 exe 会加载到旧 dll。

## 源码

- 分支：`c-1.0`
- 标签：`v1.1.1`
- 原 Electron 版保留在 `main` 分支与历史 tag / Release 中

## 播放器：视频库网格

打开播放器就是一个「库」，不再是空画面：

| 位置 | 内容 |
| --- | --- |
| 左栏 | 添加文件夹、重新扫描、已添加的文件夹（显示「N 个 · 上级路径」，可移除）、底部统计（共 N 个 / 看过 M / 上次扫描时间） |
| 右栏上部 | `全部` / `最近看过` 两个页签、搜文件名、排序（文件名自然序 / 最近添加 / 大小 / 时长）、打开文件 |
| 网格 | 每张卡片是一个视频：自动抽**首帧当封面**、右下角标时长、底部一条观看进度、下面是文件名和「看到 2:00 / 10:00」 |
| 点卡片 | 整份列表灌进播放列表，从这一条开始播；左上角 `←` 或 Esc 回到网格 |

几个细节：

- 封面是**进视口才抽**的，同时最多解码 3 个 —— 一个文件夹几百个视频也不会把界面拖卡
- WebView2 解不了的格式（部分 avi / rmvb / HEVC）留深色占位块，**不报错也不假装有封面**
- 文件名排序是「自然序」：`EP2` 在 `EP10` 前面；中文名的排在 EP 系列后面（不按拼音乱插）
- 「最近看过」里可以单条移除、可以清空，都**只动记录，不动磁盘上的文件**

## 音乐：点歌按「你看到的顺序」播

以前列表行点击传的是**曲库原索引**，播放队列也固定用曲库原顺序 —— 把列表排成
「最近添加」再点歌，播的还是老顺序，下一首跳到哪跟看到的完全对不上。
现在队列就是**当前可见的那份列表**（搜索 / 歌手筛选 / 排序之后都是），
右下角「当前播放」的编号也从 1 开始对得上。
搜索回车播第一条、首页「最近添加」卡片同样按各自的列表走。

## 音乐：「当前播放」面板每行可移除

鼠标移到某行，行尾出现垃圾桶（平时透明，不抢注意力），点它只把这首**移出队列**，
曲库文件不动。删的是正在播的这首会接着播下一首（原本停在暂停的就保持暂停），
删到空则停播。

## 已知限制（没有用假实现糊过去）

- 播放器只做「能播的封装」：部分 avi / wmv / rmvb / HEVC 播不了，
  会直接提示「用系统播放器打开」，不装作能播
- 视频库的封面每次启动重新抽（不落盘缓存），第一次滚到某个视频时有短暂空档
- 音乐每日推荐依赖官方接口，接口变了会失效（会明确报错，不静默）
- 网盘平台登录窗、联机中转帧协议 / STUN 打洞 / 虚拟网卡：仍未做
- 浏览器查找 / 阅读模式 / 手势 / 广告过滤 / 扩展：未移植
- Steam 成就同步：未做

逐条对照见 `docs/功能对照.md`。
