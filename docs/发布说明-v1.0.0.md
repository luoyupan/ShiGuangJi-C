# 拾光集 C 版 1.0.0 · 发布说明

> 此文件与 GitHub Release 文案一致，方便直接粘贴到 Release 页面。

主程序用 **C11** 重写：`ShiGuangJi.exe` 里是 Win32 窗口 + WebView2 宿主 + 内嵌 HTTP/IPC + 模块加载器；
七个模块各自编译成 **独立 dll**，放进 `modules\` 就能加载，删掉就少一个模块。
界面资源已压进 exe，交付形态就是 **exe + modules 目录**。

> 此前的 `0.4.0-c` 是测试版；本版为 **1.0.0 正式版**。

## 下载

- `ShiGuangJi-1.0.0-win64.zip`（约 5.2 MB）
- 解压后双击 `ShiGuangJi.exe` 即可，不用安装
- 需要 **Microsoft Edge WebView2 Runtime**（Win11 / 新版 Win10 一般自带）
- 数据仍在 `%APPDATA%\shiguangji\`，和原 Electron 版同一个位置，可直接沿用旧库

## 源码

- 分支：`c-1.0`
- 标签：`v1.0.0`
- 原 Electron 版保留在 `main` 分支与历史 tag / Release 中

## 这一版包含

- **游戏**：Steam / Epic / 注册表 / 目录扫描，游戏库 CRUD，启动与进程守护计时，
  游玩统计，平台总览，Steam 登录账号读取，隐藏空间（scrypt 兼容原版密码）
- **MOD**：目录规则引擎，启停 / 删除 / 导入 / 打包，创意工坊目录
- **音乐**：647 首规模曲库扫描、魔数识别格式、标签与内嵌封面、LRC 匹配、
  歌单导入导出、听歌统计、FLAC 播放与拖动进度
- **网盘**：12 家平台链接识别、下载队列、断点续传、自动解压
- **浏览器**：宿主第二个 WebView2 真实上网，标签 / 地址栏 / 书签 / 历史
- **联机**：TCP + UDP 端口映射、邀请码、房间聊天、本机网卡信息
- **图片**：照片扫描、EXIF 拍摄时间/GPS、WIC 缩略图、图片墙、足迹地图、手动标点
- **插件**：`hello.dll` 示例；第三方 dll 里可同时带清单、界面、C 后端
