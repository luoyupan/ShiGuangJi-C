# 拾光集 C 版 1.1.0 · 发布说明

> 此文件与 GitHub Release 文案一致，方便直接粘贴到 Release 页面。

这一版主要是**修 bug**：把 1.0.0 里几个「用起来别扭但一直忍着」的问题逐个修掉了，
同时把已经写完的播放器模块和几处功能更新一并放出来。

## 下载

- `ShiGuangJi-1.1.0-win64.zip`（约 1.8 MB）
- 解压后双击 `ShiGuangJi.exe` 即可，不用安装
- 需要 **Microsoft Edge WebView2 Runtime**（Win11 / 新版 Win10 一般自带）
- 数据仍在 `%APPDATA%\shiguangji\`，和 1.0.0 / 原 Electron 版同一个位置，
  **直接覆盖旧目录即可，存档不用动**

> 升级注意：主程序与 `modules\*.dll` 要**整包一起换**。只换 exe 会加载到旧 dll。

## 源码

- 分支：`c-1.0`
- 标签：`v1.1.0`
- 原 Electron 版保留在 `main` 分支与历史 tag / Release 中

## 修了什么

| 模块 | 原来的问题 | 现在 |
| --- | --- | --- |
| 浏览器 | 侧栏收藏点开后点不回去 —— 点图标只是在「书签」和「历史」之间来回切，面板永远收不起来 | 点图标开关面板；面板右上角新增「×」，Esc 也能收起 |
| 浏览器 | 搜索、点书签、点历史都在**当前页**直接打开，原来那个页面就没了 | 一律**新开标签页**，当前页保留；地址栏回车同此 |
| 浏览器 | 每次下载都要从默认目录重新找文件夹，上次选过哪不记得 | 记住上次保存的目录，下次打开对话框直接停在那里 |
| 游戏 | 同一款游戏**存两条**（Steam 清单记 `steam:AppID`，目录/注册表扫描记 `path:目录`，两套键对不上就都入库） | 按安装目录、去重键、「同名 + 同平台 + 至少一边没 AppID」三重判断，命中就合并 |
| 游戏 | **平台客户端和运行库被当成游戏**：暴雪战网、Steam / Epic / GOG / Ubisoft / EA 启动器、WeGame、Steamworks Common Redistributables、SteamVR、Steam Linux Runtime、Proton | 四个扫描源（Steam / Epic / 注册表 / 常见目录）全部过滤，入库口再兜一层；手动添加不受影响 |
| 游戏 | 已经重复的库要一条条手删 | 点一次「扫描本机游戏」会自动清理 + 合并，提示里写「合并重复 N 款，清理平台/运行库 N 项」 |
| 图片 | 地名搜索回 `301012 权限类型错误`，搜不出结果 | 补齐请求头，改走 v2 地点检索，乡镇村景点也能搜到 |
| 音乐 | 歌词匹配、每日推荐的「删除 / 保留 / 移动」是三个空壳，点了没反应 | 已接通 |

游戏的合并规则：补空字段（封面 / 主程序 / 发行商 / AppID），游玩时长与次数取大，
收藏与隐藏取或，分类做并集（手动锁定的分类不动），信息更全的那条留作主体。
新增 `games:tidy` 通道，可重复调用、幂等。

## 这一版新增

- **播放器模块**（`player.dll`，可在设置里关掉）：单个文件 / 整个文件夹打开、
  自然序播放列表、进度拖动、0.5~3 倍速、全屏、顺序/单曲/随机、空格与方向键快捷键、
  自动挂同名 `srt / ass / ssa / vtt` 字幕（GBK 解码、ASS 覆盖标签清洗）、
  一键截图存 PNG、每 5 秒记进度续播
- **音乐**：多站合一音源真的能下载了（搜索 → 取直链 → 下载 → 自动入库）；
  每日推荐改读官方推荐接口；复用浏览器里已登录的网易云 / QQ 状态读取「我的歌单」；
  封面三级兜底（内嵌 → 同目录 cover → 在线专辑图）
- **图片**：足迹地图随窗口纵向自适应；大图查看器接近整窗并支持滚轮缩放 / 拖动平移；
  批量标注（多选一次套用同一坐标或地名）
- **游戏**：封面抓取（本地 librarycache 优先，其次 Steam CDN）、
  Steam 完整库统计、卸载按平台走不同路径并明确告知「会怎么卸」

## 已知限制（没有用假实现糊过去）

- 播放器只做「能播的封装」：部分 avi / wmv / rmvb / HEVC 播不了，
  会直接提示「用系统播放器打开」，不装作能播
- 音乐每日推荐依赖官方接口，接口变了会失效（会明确报错，不静默）
- 网盘平台登录窗、联机中转帧协议 / STUN 打洞 / 虚拟网卡：仍未做
- 浏览器查找 / 阅读模式 / 手势 / 广告过滤 / 扩展：未移植
- Steam 成就同步：未做

逐条对照见 `docs/功能对照.md`。
