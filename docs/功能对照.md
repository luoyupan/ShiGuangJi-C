# 功能对照表（Electron 原版 → C 版）

> 图例：**✅ 已实现**（行为对齐原版）｜**🟡 可用但简化**｜**⬜ 未实现**（界面存在，操作会给出明确原因）

原版代码位置以交接包 `02-源码/` 为准。C 版对应位置在 `src/modules/<模块>/module.c` 与
`src/host/*.c`。

---

## 9. 这轮实际验证过的

- 8 个 dll 全部加载；`hello.dll` 删/放能增减卡片
- 原有真实库：23 款可见游戏 / 219 款总库 / 647 首曲目 / 1030 张照片
- 游戏扫描：Steam 46 已安装、注册表候选 14、新增 7
- 音乐：扫描 647 首 0.2s；FLAC 播放、拖动进度（HTTP Range）、LRC 解析（1 行纯音乐词）
- 图片：1030 张列表、WIC 缩略图、中国地图 2 个 GPS 别针、无根目录重扫不丢数据
- 网盘：真实下载 `robots.txt` 2814 字节，状态 done
- 联机：建房/邀请码/解析/停止；UDP/TCP 端口监听
- 浏览器：WebView2 加载 `cn.bing.com`，地址栏/标题/前进状态同步
- 隐藏空间：scrypt 输出与 Node `crypto.scryptSync` 逐字节一致（用真实 salt/hash 校验）
- 内嵌 UI：删掉 `ui\` 后仍能从 exe 的 `UI_ZIP` 解出并启动
